# GAZE OS

가제 데스크톱 앱 설치 파일을 올려 두는 곳입니다. 이 저장소에는 설치 파일만 있습니다.

## 받기

맥 전용입니다. [최신 릴리즈](https://github.com/hykeelson/GAZE-OS-releases/releases/latest)에서 `GAZE-OS-<판>-mac-universal.dmg` 하나를 받습니다.

.zip · .blockmap · latest-mac.yml 같은 나머지 파일은 자동 업데이트에 씁니다. 받지 않아도 됩니다.

## 설치하고 처음 열기 (macOS 15 이상)

1. 받은 dmg 를 열고 GAZE OS 를 「응용 프로그램」 폴더로 끌어 놓습니다.
2. 응용 프로그램 폴더에서 GAZE OS 를 더블클릭합니다. 「열리지 않음」 창이 뜨면 「완료」를 누릅니다.
3. 시스템 설정 → 개인정보 보호 및 보안으로 갑니다. 아래쪽 보안 칸에서 「그래도 열기」를 누릅니다.
4. 암호나 Touch ID 로 확인하면 열립니다.

한 번 열고 나면 다음부터는 그냥 열립니다.
dmg 안에서 바로 연 앱은 업데이트가 되지 않으니, 꼭 응용 프로그램 폴더로 옮겨서 여세요.

## 업데이트

따로 받을 필요가 없습니다. 앱이 새 판을 찾아 받아 두고, 다 받으면 「지금 다시 시작 / 나중에」를 묻습니다.
「나중에」를 고르면 다음에 다시 물을 때 바뀝니다.
